# 🔐 Projeto Login Interativo

## 🚀 Sobre o projeto

Projeto de tela de login desenvolvido em **HTML, CSS e JavaScript**, com foco em adicionar **mais interatividade** em relação ao primeiro projeto de login.
O objetivo foi treinar manipulação do DOM e efeitos visuais que deixam a experiência do usuário mais dinâmica.

## 🌐 Demonstração

👉 [Acesse a página no GitHub Pages](https://lepofernandes.github.io/Projeto-Login-Interativo/)
👉 [Repositório no GitHub](https://github.com/LepoFernandes/Projeto-Login-Interativo)

## 🛠 Tecnologias

* HTML5
* CSS3
* JavaScript

## ⚙️ Como rodar localmente

1. Clone o repositório:

   ```bash
   git clone https://github.com/LepoFernandes/Projeto-Login-Interativo.git
   ```
2. Acesse a pasta do projeto:

   ```bash
   cd Projeto-Login-Interativo
   ```
3. Abra o arquivo `index.html` no navegador.

## 📌 Aprendizados

Esse projeto me ajudou a:

* Reforçar conceitos de manipulação do DOM
* Criar efeitos de interação entre usuário e formulário
* Explorar melhorias em relação à primeira tela de login
